## Project Overview

This project studies approximate Bayesian inference in the Matchbox recommendation model. The main question is how Assumed-Density Filtering (ADF) and repeated Expectation Propagation (EP) affect predictive quality and computational cost.

The project uses the MovieLens 1M dataset as the main benchmark. Planned experiments include ADF vs. repeated EP, different latent dimensions, metadata vs. no metadata, and sparse / cold-start settings.
